# Detecting the Provider

To detect if a user has already installed UnionKey, a web application should check for the existence of a `window.$unionkey.iolana` object.

UnionKey Browser Extension, UnionKey Mobile APP and UnionKey Desktop in-app browser will both inject a `$unionkey.iolana` object into the `window` of any web application the user visits.

If a `window.$unionkey.iolana` object exists, Solana apps can interact with UnionKey via the API found at `window.$unionkey.iolana`. This `solana` object is also available at `window.solana` to support legacy integrations.&#x20;

To detect if UnionKey is installed, an application should check for an additional `isUnionKey` flag.

```javascript
const isUnionKeyInstalled = window.$onekey?.solana?.isUnionKey;
```

If UnionKey is not installed, we recommend you redirect your users to [https://unionkey.io/download/?client=browserExtension](https://unionkey.io/zh\_CN/download/?client=browserExtension). Altogether, this may look like the following.

```javascript
const getProvider = () => {
  if ('$onekey' in window) {
    const provider = window.$onekey?.solana;

    if (provider?.isUnionKey) {
      return provider;
    }
  }

  window.open('https://unionkey.io/download/?client=browserExtension', '_blank');
};
```
