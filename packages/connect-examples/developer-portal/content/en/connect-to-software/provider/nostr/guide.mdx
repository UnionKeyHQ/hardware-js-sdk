# Guide

## Overview

This guide helps users understand how to use the UnionKey provider API to easily build network applications using the Nostr protocol.

UnionKey provider API is specified by [NIP-07](https://github.com/nostr-protocol/nips/blob/master/07).

## Install

#### 1. Download UnionKey Wallet

Download the [UnionKey Wallet](https://unionkey.io/download?client=browserExtension). Install the UnionKey browser extension.

#### 2. API Injection Explanation

* The UnionKey browser extension injects `Provider API` into visited websites.
* Two types of APIs are provided: `window.nostr` and `window.$onekey.nostr`.
* It is recommended to use `window.$onekey.nostr`.

> Both APIs have the same functionality, just different names.

### Detecting Provider API support

Before you start using Nostr protocol you need to check for browser support by checking if the variable `window.nostr` is defined:

```javascript
const provider = (window.$onekey && window.$onekey.nostr) || window.nostr;

if (!provider) {
  alert("No Provider available.");
}
```
