# Introduction

Developer-focused documentation for integrating UnionKey hardware in Web and Native apps.

This page is the **orientation layer** — pick the right SDK package for your platform and install it. For the end-to-end walkthrough (search → events → PIN/passphrase → first signing call) plus parameters, events, and error handling, see the [Core API Guide](/en/hardware-sdk/core-api-guide).

## Choose Your Transport

USB integrations should use `@unionkeyfe/hd-common-connect-sdk`; use `@unionkeyfe/hd-web-sdk` only when the host mandates an iframe/plugin setup.

### Connection Methods

| Method | Description | Supported devices |
|--------|-------------|-------------------|
| **USB / WebUSB** | Wired USB; Web via WebUSB, native via low-level plugin | All UnionKey devices |
| **Bluetooth BLE (native)** | Native apps over BLE (not Web Bluetooth); requires OS Bluetooth & permission | UnionKey Pro, Touch, Classic 1s / Classic 1s Pure; **Mini does not support BLE** |
| **Air-Gap (QR)** | Offline QR signing | UnionKey Pro only |

## Install SDK

Pick one entry by runtime:

```bash
# Web / desktop WebUSB (recommended)
npm i @unionkeyfe/hd-common-connect-sdk

# React Native BLE
npm i @unionkeyfe/hd-ble-sdk

# Native host with low-level plugin (Android/iOS/Flutter bridge)
npm i @unionkeyfe/hd-common-connect-sdk

# Plugin iframe host only (plugin-only)
npm i @unionkeyfe/hd-web-sdk
```

Transport details:
- WebUSB: [WebUSB guide](/en/hardware-sdk/transport/web-usb)
- React Native BLE: [BLE guide](/en/hardware-sdk/transport/react-native-ble)
- Native Android / iOS / Flutter: bridge JS calls through low-level transport plugins (see pages for examples).
- Custom channel & protocol: [Low-Level Transport Plugin & Protocol](/en/hardware-sdk/concepts/low-level-plugin)

## Initialize the SDK

Use the initialization method that matches your runtime—avoid mixing SDK entries.

### Web / Desktop WebUSB

Use `@unionkeyfe/hd-common-connect-sdk`:

```ts
import HardwareSDK from '@unionkeyfe/hd-common-connect-sdk';

await HardwareSDK.init({
  env: 'webusb',
  debug: process.env.NODE_ENV !== 'production',
  fetchConfig: true,
});
```

### React Native BLE

Use `@unionkeyfe/hd-ble-sdk`:

```ts
import HardwareSDK from '@unionkeyfe/hd-ble-sdk';

await HardwareSDK.init({
  debug: __DEV__,
});
```

### Native Bridge / Low-level

Use `@unionkeyfe/hd-common-connect-sdk`:

```ts
import HardwareSDK from '@unionkeyfe/hd-common-connect-sdk';

await HardwareSDK.init({
  env: 'lowlevel',
  debug: process.env.NODE_ENV !== 'production',
  fetchConfig: true,
});
```

| Environment | Use Case |
|-------------|----------|
| `webusb` | Browser WebUSB (no iframe) |
| `lowlevel` | Native apps bridging JS via low-level adapter |
| `react-native` | Custom RN bridge or Electron BLE |
| `emulator` | Built-in emulator transport |

### Plugin Iframe Host

Use `@unionkeyfe/hd-web-sdk` (plugin-only):

```ts
import { HardwareSDK } from '@unionkeyfe/hd-web-sdk';

await HardwareSDK.init({
  debug: process.env.NODE_ENV !== 'production',
  connectSrc: 'https://jssdk.unionkey.io/1.1.19/', // iframe host
});
```

- Standard lifecycle (`init → search → getFeatures → subscribe → call + uiResponse → cleanup`): [Core API Guide → Standard lifecycle](/en/hardware-sdk/core-api-guide#standard-lifecycle)
- Call parameters accepted by every method: [Common params](/en/hardware-sdk/core-api-guide#common-params)
- Identifier reference (`connectId` / `deviceId` / `passphraseState` / …): [Identifiers](/en/hardware-sdk/concepts/identifiers)
- PIN entry flow: [PIN Code](/en/hardware-sdk/concepts/pin)
- Passphrase / hidden-wallet flow: [Passphrase](/en/hardware-sdk/concepts/passphrase)
