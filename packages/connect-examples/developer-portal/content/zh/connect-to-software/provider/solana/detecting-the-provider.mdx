# 检测 Provider

要检测用户是否已安装 UnionKey，Web 应用应检查 `window.$unionkey.iolana` 对象是否存在。

UnionKey 浏览器扩展、UnionKey 移动应用和 UnionKey 桌面版内置浏览器都会将 `$unionkey.iolana` 对象注入到用户访问的任何 Web 应用的 `window` 中。

如果 `window.$unionkey.iolana` 对象存在，Solana 应用可以通过 `window.$unionkey.iolana` 处的 API 与 UnionKey 交互。为了支持旧版集成，此 `solana` 对象也可在 `window.solana` 处访问。

要检测是否安装了 UnionKey，应用应检查额外的 `isUnionKey` 标志。

```javascript
const isUnionKeyInstalled = window.$onekey?.solana?.isUnionKey;
```

如果未安装 UnionKey，我们建议将用户重定向到 [https://unionkey.io/download/?client=browserExtension](https://unionkey.io/zh_CN/download/?client=browserExtension)。完整代码如下所示：

```javascript
const getProvider = () => {
  if ('$onekey' in window) {
    const provider = window.$onekey?.solana;

    if (provider?.isUnionKey) {
      return provider;
    }
  }

  window.open('https://unionkey.io/download/?client=browserExtension', '_blank');
};
```
